# 시험 판정 규칙

`data/test-cases.csv`의 시험 항목마다 `data/logs`의 로그를 읽어 Pass, Fail, 판정 불가 중 하나로 판정합니다.
규칙을 바꾸면 `scripts/judge.js`의 상수와 `tests/cases.json`을 함께 고칩니다.

## 로그 형식

로그는 1초 간격의 CSV 파일입니다.
열 이름은 아래 이름 중 하나를 사용하며, 판정에 쓰지 않는 열은 무시합니다.

| 의미 | 열 이름 |
| --- | --- |
| 경과 시간(초) | `time_s`, `시간(초)` |
| 기준 온도 | `ref_c`, `기준온도` |
| 센서 온도 | `sensor_c`, `센서온도` |
| 전원 전압 | `supply_v`, `전원전압` |

인코딩은 UTF-8과 CP949(엑셀의 'CSV (쉼표로 분리)' 저장)를 모두 읽습니다.

## 허용 오차

오차는 `센서 온도 - 기준 온도`입니다.
허용 오차는 `docs/spec-ts100.md`의 REQ-02(측정 정확도)를 따르며, 시험의 목표 온도로 정합니다.

| 목표 온도 | 허용 오차 |
| --- | --- |
| -10도 이상 85도 이하 | 0.5도 |
| 그 밖의 온도 | 1.0도 |

-10도와 85도는 0.5도 구간에 포함됩니다.

## 판정

1. 로그 시작 후 300초는 챔버 온도가 안정되는 구간이라 오차 판정에서 제외합니다.
1. 샘플 간격이 3초를 넘는 곳이 있으면 Fail입니다. 비고: 기록 끊김
1. 안정화 구간 이후 오차의 절댓값이 허용 오차를 넘는 샘플이 하나라도 있으면 Fail입니다. 비고: 오차 초과
1. 위에 해당하지 않으면 Pass입니다.

## 판정 불가

판정할 근거가 부족하면 억지로 판정하지 않고 판정 불가로 남깁니다.

| 상황 | 비고 |
| --- | --- |
| 로그 파일이 없음 | 로그 없음 |
| 필수 열(시간, 기준 온도, 센서 온도)이 없음 | 열 누락 |
| 필수 열에 비어 있거나 숫자가 아닌 값이 있음 | 값 오류 |
| 안정화 구간 이후 샘플이 600개 미만 | 샘플 부족 |
