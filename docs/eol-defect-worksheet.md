# 업무 분해 시트: EOL 검사 불량 집계

사용자 답변을 반영했습니다. 판단 기준은 [확정 규칙](./eol-defect-rules.md)을 따릅니다.

## 업무 개요

| 항목 | 내용 |
| --- | --- |
| 업무 | EOL 검사 기록에서 최종 검사 기준으로 월별 불량 제품 수 집계 |
| 영문 이름 | `eol-defect` |
| 주기 | 확인 필요: 입력은 연간 기록이며 실행 주기는 미정 |
| 입력 | `practice/eol-results.csv` — EOL 검사기에서 내보낸 연간 CSV |
| 열 | 검사번호, 검사시각, 라인, 시리얼, 검사항목, 측정값, 하한, 상한, 비고 |
| 현재 순서 | 엑셀에서 불합격 행 필터링 → 월별 불량 제품 수 집계 |
| 결과물 | 월별 불량 제품 수 표, 불량이 가장 많은 달, 검증 상태와 확인 필요 항목 |
| 저장 위치 | `output/eol-defect-result.md`, `.json` 및 검증 결과 |
| 받는 사람 | 품질 파트장 |

## 단계

집계 범위는 같은 입력 파일 전체이며 원본은 보존합니다.

| 순서 | 하는 일 | 판단 기준 | 맡길 곳 |
| --- | --- | --- | --- |
| 준비 | 원본 범위와 기준 확인 | 확정 규칙과 입력 파일 확인 | 사람 |
| 입력 | 원본 보존 후 CSV 구조 검사 | 필수 열, 인코딩, 값 형식, 검사 식별 방식 | 스크립트 |
| 제외 | 마스터 샘플과 통신 오류 행 분리 | 시리얼 `MST` 시작, 측정값 `ERR`; 제외 내역 보존 | 스크립트 |
| 검사 구성 | 검사항목 행을 검사 단위로 묶기 | 시리얼·검사번호로 구성, ERR 제외 후 다시 잰 유효 값 사용 | 스크립트 |
| 최종 선택 | 시리얼별 마지막 검사 선택 | 여러 날짜 형식 해석, 검사시각 → 검사번호 순서 | 스크립트 |
| 판정 | 선택한 검사의 항목 판정 통합 | mV를 V로 변환, 음수 포함, 하한·상한 포함 비교 | 스크립트 |
| 집계 | 월별 불량 제품 수 및 최다 월 산출 | 시리얼별 최종 불합격 제품을 마지막 검사 월에 귀속, 최다 월 동률 모두 표시 | 스크립트 |
| 검증 | 가짜 케이스의 기대·실제 대조 | 불일치하면 집계 중단, 결과 파일 저장 | 스크립트 |
| 요약 | 결과 파일에 근거해 보고 초안 작성 | 숫자를 직접 계산하지 않음, 미확정 기준 및 판정 불가 표시 | 모델 |
| 검토 | 보고서와 전달 내용 확인 | 미검증 결과를 확정 결과로 전달하지 않음 | 사람 |
| 전달 | 품질 파트장에게 공유 | 전달 대상·내용·채널을 먼저 보여 주고 명시적 승인 | 사람 승인 |

## 맡길 곳을 정하는 기준

| 이런 일 | 맡길 곳 |
| --- | --- |
| CSV 검사, 제외, 최종 검사 선택, 범위 판정, 월별 집계, 검증 | 스크립트 |
| 결과 파일을 근거로 요약, 불일치 시 확인할 항목 정리 | 모델 |
| 애매한 기준 확정, 검토, 외부 전달 승인 | 사람 |

## 검증

| 확인할 것 | 방법 |
| --- | --- |
| 정상·경계·판정 불가 처리 | `node scripts/eol-defect.js --check`, [검증 케이스](../tests/eol-defect-cases.json)의 기대·실제 확인 |
| 재검사 제품 중복 집계 방지 | 같은 시리얼의 이전 불합격이 최종 합격으로 대체되는지 확인 |
| 제외와 불확실성 구분 | 마스터·통신 오류 제외 내역과 판정 불가 사유를 결과 파일에 별도로 기록 |
| 이번 수작업 결과 재현 | 이번 요청에서만 같은 파일의 참고값과 대조, 상시 스킬에 넣지 않음 |
| 요약 숫자 정확성 | 스크립트가 생성한 결과 파일의 값만 인용 |
| 전달 통제 | 승인 전에는 품질 파트장에게 전송하지 않는지 확인 |

## 실행

```sh
node scripts/eol-defect.js
```

검증셋 실행 후 실제 집계를 진행합니다. 보고서는 로컬에 저장하며 품질 파트장 전달은 별도 승인이 필요합니다.
