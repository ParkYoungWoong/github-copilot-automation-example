# TS-100 온도 센서 모듈 사양

연구개발팀이 개발한 산업용 온도 센서 모듈의 기준 사양입니다.
값을 바꾸려면 파트장 승인 후 이 문서를 먼저 수정합니다.

## 측정 사양

| ID | 항목 | 값 |
| --- | --- | --- |
| REQ-01 | 측정 범위 | -40도에서 125도 |
| REQ-02 | 측정 정확도 | -10도 이상 85도 이하는 0.5도 이내, 그 밖의 구간은 1.0도 이내 |
| REQ-03 | 분해능 | 0.1도 |
| REQ-04 | 샘플링 주기 | 기본 1초 |

## 전기 사양

| ID | 항목 | 값 |
| --- | --- | --- |
| REQ-05 | 동작 전압 | 3.3V, 허용 범위 3.0V에서 3.6V |
| REQ-06 | 소비 전류 | 측정 시 12mA, 대기 시 0.8mA |

## 환경 사양

| ID | 항목 | 값 |
| --- | --- | --- |
| REQ-07 | 연속 동작 | 8시간 연속 측정 중 데이터 누락 없음 |
| REQ-08 | 동작 온도 | -40도에서 85도 |
