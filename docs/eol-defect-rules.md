# EOL 검사 불량 집계 규칙

상태: 사용자 답변을 반영한 확정 규칙. 제공되지 않은 판단 기준은 추가하지 않습니다.

## 입력과 범위

- 원본: `practice/eol-results.csv`. 파일 안의 모든 기록을 대상으로 하며, 파일 밖의 이력은 조회하지 않습니다.
- 열: `검사번호`, `검사시각`, `라인`, `시리얼`, `검사항목`, `측정값`, `하한`, `상한`, `비고`.
- CSV의 BOM, 인용 필드, 쉼표·줄바꿈·따옴표가 포함된 비고를 읽습니다. 필수 열 누락·중복 및 행의 열 수 오류는 실행 오류로 알립니다.
- 원본은 수정하지 않습니다.

## 처리 순서

| 단계 | 확정 기준 |
| --- | --- |
| 마스터 제외 | 시리얼이 정확히 `MST`로 시작하는 제품 제외 |
| 검사 구성 | 같은 시리얼·같은 검사번호의 행을 같은 검사로 구성. 라인이 달라도 같은 시리얼이면 같은 제품 |
| 통신 오류 제외 | 측정값이 정확히 `ERR`인 행만 측정 판정에서 제외. 같은 검사번호 안의 다시 잰 유효 값은 사용 |
| 수치 해석 | 음수는 정상적인 수치. `mV` 값은 1000으로 나눠 V로 비교. `V` 접미사는 단위 표시로 해석 |
| 항목 판정 | 단위를 맞춘 후 `하한 <= 측정값 <= 상한`이면 합격 |
| 검사 판정 | 유효 측정 항목 중 하나라도 범위 밖이면 해당 검사 불합격 |
| 최종 검사 | 시리얼별 검사시각이 가장 나중인 검사 선택. 시각이 같으면 검사번호 순서상 나중인 검사 선택 |
| 월 귀속 | 마지막 검사의 검사시각에 해당하는 연월 |
| 제품 집계 | 최종 검사가 불합격인 시리얼을 월별로 집계. 불량 항목·불합격 행이 여럿이어도 제품은 중복 집계하지 않음 |
| 최다 월 | 월별 불량 제품 수가 가장 큰 달을 모두 표시. 동률이면 어느 달도 생략하지 않음 |

`ERR` 행도 검사 식별과 시각 확인에는 사용합니다. 마지막 검사에서 `ERR`을 제외한 유효 측정값이 없으면 판정 불가이며, 이전 검사로 자동 복귀하지 않습니다. `ERR` 재측정이 아닌 유효 수치 행은 임의로 버리지 않고 항목 판정에 사용합니다.

## 시각 및 정렬 해석

- 입력 프로파일에서 확인한 `YYYY-MM-DD HH:mm:ss`, `YYYY.MM.DD HH:mm`, `YYYY년 M월 D일 HH:mm`을 모두 읽습니다.
- 검증 및 동일 구조 입력을 위해 날짜 구분자 `/`, 날짜·시각 구분자 `T`, 선택적인 초·밀리초도 지원합니다.
- 초가 없는 값은 해당 분의 시작으로 해석합니다.
- 시간대 표기가 없는 입력은 기록된 달력 시각 그대로 비교·월 귀속합니다. 실행 PC의 시간대에 따라 값이 달라지지 않으며 임의 시간대 변환을 하지 않습니다.
- 검사번호는 숫자 부분을 수치 순서로 비교하는 자연 정렬을 사용합니다. 자연 정렬상 같으면 원문 문자열 순서로 비교합니다.
- 같은 시리얼·검사번호 안의 시각이 서로 다르거나, 지원하지 않는 형식·존재하지 않는 날짜가 있으면 그 제품은 최종 검사 선택 불가로 표시합니다. 파일 행 순서로 대신 선택하지 않습니다.

## 판정 불가와 표시 정책

- 실제 입력에는 측정값 `-`인 행이 없으며 음수는 유효합니다. 향후 `-` 등 해석할 수 없는 값이 들어와도 임의 제외하지 않습니다.
- 빈 식별자, 잘못된 수치·한계값, 하한이 상한보다 큰 경우는 사유와 근거행을 기록합니다.
- 최종 검사의 수치가 잘못되면 그 제품을 판정 불가로 표시합니다. 이전 검사의 수치 오류가 최종 검사의 유효 판정을 대체하지 않습니다.
- 필수 검사항목 목록은 제공되지 않았으므로 별도 누락 항목 기준은 만들지 않습니다. 제공된 유효 측정 항목으로 판정하며, 항목 완전성 검증은 수행하지 않았음을 보고서에 명시합니다.
- 판정 불가 제품이나 식별 불가 행이 있으면 전체 집계는 확정 보류로 표시하고 종료 코드로도 알립니다.
- 월별 표에는 마스터를 제외한 입력에 유효한 검사시각이 있는 모든 월을 표시합니다. 최종 불량이 없는 월도 표시합니다.
- 불량 제품이 전혀 없으면 최다 불량 월은 ‘없음’으로 표시합니다. 최종 검사시각을 알 수 없는 제품은 임의의 월에 배정하지 않습니다.

## 실행과 결과물

```sh
node scripts/eol-defect.js --check
node scripts/eol-defect.js
```

- 실행 시 [검증셋](../tests/eol-defect-cases.json)을 먼저 확인하며 불일치하면 집계를 진행하지 않습니다.
- `output/eol-defect-check.json`, `.md`: 케이스별 기대·실제·일치 여부.
- `output/eol-defect-profile.json`: 검사시각·측정값 형식 분포.
- `output/eol-defect-result.json`, `.md`: 월별 표, 최다 월, 판정 및 제외·판정 불가 근거.
- 모델은 스크립트 결과 파일의 숫자만 인용합니다. 원인 대신 확인할 항목을 적습니다.
- 품질 파트장에게 보낼 내용·대상·채널을 먼저 보여 주고 명시적 승인을 받습니다. 스크립트는 외부 전송을 하지 않습니다.

## 이번 검증의 수작업 비교

같은 입력 파일의 사용자 제공 참고값은 불량 제품 수 515개, 최다 불량 월 2026년 3월, 해당 월 52개입니다.

```sh
node scripts/eol-defect.js --compare 515 2026-03 52
```

- 비교 옵션은 이번 요청에서만 사용합니다. 참고값은 코드에 고정하지 않고 실행 인자로 받습니다.
- `output/eol-defect-comparison.json`, `.md`에 기대값·실제값·차이·일치 여부를 기록합니다.
- 이 비교를 상시 판정 기준이나 스킬 실행 단계에 넣지 않습니다.
- 참고값에 맞추려고 규칙이나 원본을 바꾸지 않습니다. 총수·최다 월 일치만으로 월별 표 전체가 검증되었다고 표시하지 않습니다.
